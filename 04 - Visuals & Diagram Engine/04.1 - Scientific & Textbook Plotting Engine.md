## 🎨 Master Matplotlib Styling Rules
To ensure diagrams look like they came from an academic textbook (Pearson / Cambridge / McGraw-Hill) rather than an AI image generator:
1. **Typography:** Use serif fonts (`DejaVu Serif`, `Times New Roman`, or `Computer Modern`).
2. **Color Palette:** Monochrome / Greyscale with subtle accents (`#000000`, `#333333`, `#777777`, `#F8F9FA`). Avoid neon or saturated palettes.
3. **Resolution:** Strict `dpi=300` for ultra-sharp print quality.
4. **Linewidths:** Hairline and clear axes (`linewidth=0.8` to `1.5`).
5. **Figure Captions:** Numbered formal captions in bold Times New Roman (`Figure 1: ...`).

---

## 🐍 Reusable Matplotlib Template
```python
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.family'] = 'serif'
plt.rcParams['font.serif'] = ['Times New Roman', 'DejaVu Serif']
plt.rcParams['mathtext.fontset'] = 'cm'
plt.rcParams['axes.edgecolor'] = '#333333'
plt.rcParams['axes.linewidth'] = 0.8

fig, ax = plt.subplots(figsize=(6.5, 3.5), dpi=300)
x = np.linspace(0, 10, 200)
y = np.sin(x)
ax.plot(x, y, color='#000000', linewidth=1.5, label='f(x)')
ax.grid(True, linestyle=':', alpha=0.6)
ax.set_title('Figure Title', fontsize=10.5, fontweight='bold')
plt.tight_layout()
plt.savefig('output.png', dpi=300)
```
