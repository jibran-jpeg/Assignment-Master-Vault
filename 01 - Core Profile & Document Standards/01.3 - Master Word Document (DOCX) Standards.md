# 📐 01.3 - Master Word Document (DOCX) Standards

## 🎨 Strict Color Palette: 100% Standard Black
* **Document Text Color:** `#000000` (Strict RGB `0, 0, 0`).
* **Heading Colors:** `#000000` (Strict RGB `0, 0, 0`).
* **Table Borders:** Academic dark charcoal / black (`#222222` or `#000000`).
* **THE AI ACCENT BAN:** Absolutely NEVER use blue, cyan, teal, or purple for section headers, bullet dots, or callouts. Modern AI tools default to corporate blue headers (`#0056B3`, `#1E90FF`). In university papers, colored headers scream AI generation.

---

## 🔤 Typography & Hierarchy Scale
* **Primary Font Family:** `Times New Roman` throughout the entire document (or `Calibri` only if the professor's input document was explicitly set in Calibri).
* **Document Heading 1:** 13.5pt – 14.0pt, Bold, `#000000`, 16pt space before, 6pt space after, `keep_with_next = True`.
* **Document Heading 2:** 11.5pt – 12.0pt, Bold, `#000000`, 10pt space before, 4pt space after, `keep_with_next = True`.
* **Document Heading 3:** 11.0pt – 11.5pt, Bold, `#000000`, 8pt space before, 2pt space after, `keep_with_next = True`.
* **Body Paragraphs:** 11.0pt Regular, `#000000`, 1.15 Line Spacing, 0pt space before, 6pt space after, Justified alignment (`WD_ALIGN_PARAGRAPH.JUSTIFY`).
* **List Bullets:** 11.0pt, 1.15 Line Spacing, 4pt space after, bold run prefix for bullet title (`style="List Bullet"`).

---

## 📊 Professional Engineering & Data Table Standards (Crisp Grid Borders)
* **The "Floating Table" Trap Banned:** Never produce bare 3-line tables with zero vertical or interior borders for engineering data or matrices. Having numbers floating in wide empty space looks unfinished and gives an artificial, AI-generated skeleton appearance.
* **Defined Grid Borders:** All engineering tables, matrix grids, and numerical calculation tables MUST feature clean, crisp grid lines:
  * Top and bottom outer borders: `#333333` (solid 0.75pt–1.0pt / `sz="8"`).
  * Left and right outer borders: `#B0B0B0` (solid 0.5pt / `sz="4"`).
  * Interior horizontal dividers (`w:insideH`): subtle single rule (`#B0B0B0` / `sz="4"`).
  * Interior vertical column dividers (`w:insideV`): subtle single rule (`#B0B0B0` / `sz="4"`).
* **Shaded Column Header Row:** The top header row MUST have subtle neutral background shading (`#EAEAEA` or `#E0E0E0`) with bold text and a dark separator line beneath (`#333333`, `sz="8"`).
* **2D Matrix Array Presentation:** For 2D matrices (e.g. 7×7 image arrays), shade the column headers (`#EAEAEA`), row headers (`#F0F0F0`), and the junction cell (`#D9D9D9`). Use compact padding so the matrix reads as a cohesive 2D spatial grid.
* **Alternating Row Shading:** For large calculation tables (20+ rows), use subtle alternating row shading (`#FFFFFF` and `#F8F9FA`) to maximize legibility.
* **Table Numbering & Captions:** Formal academic caption above table: **Table 1** (10pt bold) followed by *Italic Descriptive Title* (10pt italic).
* **Row Integrity:** All rows must have `<w:cantSplit/>` to prevent mid-cell splits across pages, and the header row must have `<w:tblHeader/>`.

---

## 🚫 Absolute Callout Box Ban (Zero Exceptions)
* **Strict Universal Ban:** NEVER use single-cell bordered callout boxes, 1x1 tables, or containers with thick left accent borders (`border-left`) and grey background shading (`#F9F9F9`, `#F5F5F5`, `#FBFBFB`) for ANY content in Microsoft Word. This includes summaries, takeaways, notes, code snippets, AND mathematical formulas. Real students never create web-style CSS markdown quote blocks in Word.
* **Zero Exceptions for Math or Formulas:** Mathematical equations must NEVER be placed inside bordered cells or grey boxes. They must be formatted as clean, borderless centered paragraphs using native Times New Roman typography with variables italicized and proper sub/superscripts.

---

## 🔢 Authentic Mathematical Equation Formatting Standard
* **Paragraph Structure:** Equations are standalone centered paragraphs with 3pt–4pt space before and 3pt–4pt space after, with line spacing set to 1.15.
* **Border & Background:** 100% borderless, transparent background (`#FFFFFF`). NO tables, NO borders, NO shaded boxes.
* **Typography:**
  * Variables (*r*, *s*, *k*, *f*, *x*, *y*, *z*, *T*, *G*, *p*, *n*) MUST be in *Times New Roman Italics*.
  * Numbers, parentheses, and standard operators (255, round, =, +, -, ×, ∑, ∫, argmin) MUST be in Regular Times New Roman.
  * Subscripts and superscripts must be formatted using native Word properties (`font.subscript = True`, `font.superscript = True`), never raw markdown underscores or carets like `r_k` or `2^8`.
  * Proper Unicode symbols: Use real symbols (×, ∑, ∫, Δ, ∇, μ, σ, ≈, ≤, ≥, →) instead of ASCII approximations (`*`, `sum`, `int`, `Delta`, `==>`).
* **Equation Numbering:** Place clean parentheses labels like `(1)` or `(2.1)` tab-aligned to the right or centered cleanly beside the formula. Only number formulas that are actively referenced.

---

## 📑 Footer & Dynamic Page Numbering
* **Header / Footer Font:** Times New Roman 9.0pt – 9.5pt, Bold or Neutral Grey (`#646464`).
* **Left Footer:** Subject Name (e.g., `Business Technology and Ethics` or `Digital Image Processing`).
* **Right Footer:** Campus / Course Code (e.g., `DEPT-01` or `INST-CAMPUS`) or Dynamic Word Field: `Page X of Y` via automated Word XML fields (`<w:fldChar w:fldCharType="begin"/>`, `<w:instrText> PAGE </w:instrText>`).
