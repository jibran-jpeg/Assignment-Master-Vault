# 👤 01.1 - Dynamic Student Profile & Institutional Adapter

## 🎓 Universal Student Profile Architecture
This vault is engineered to adapt dynamically to **any student, any university, and any academic discipline**. Rather than hardcoding personal details, all credentials and institutional patterns are resolved via a local configuration file (`student_profile.json`) or prompted interactively before assignment generation.

### ⚙️ Quick Profile Setup
To configure or update your personal credentials on your local machine, run the interactive setup wizard:

```bash
python setup_profile.py
```

This generates a local `student_profile.json` (automatically ignored by git so your private academic details are never exposed).

## 📋 Profile Parameters Schema

Whenever an AI agent or generation script creates an assignment, it reads and binds these parameters:

| Parameter Key | Description | Example Value |
| :--- | :--- | :--- |
| `student_name` | Full Legal / University Name | `John Doe` |
| `student_id` | Student Roll / Registration Number | `2024-CS-042` |
| `degree_program` | Enrolled Degree Program | `Bachelor of Science in Computer Science` |
| `current_standing`| Current Semester / Academic Standing | `6th Semester / Senior Year` |
| `class_section` | Assigned Section / Cohort | `Section B` |
| `institution_name`| Full University / College Name | `Faculty of Computing & Information Technology` |
| `campus_name` | Specific Campus or Branch | `Main Campus` |
| `department` | Academic Department | `Department of Software Engineering` |
| `output_dir` | Target Directory for Generated Docs | `./output/assignments/` |

## 🏛️ Institutional Header & Cover Layout Patterns

Different universities and course instructors enforce distinct cover layouts. The assignment engine dynamically adapts to the professor's pattern:

### Pattern A: Formal Two-Column Header with Logo & Underline
* **Left Column:** Official University Crest / Logo (width ~1.5 to 1.8 inches).
* **Right Column:**
  * Top Line: `{{INSTITUTION_NAME}}` (Times New Roman, 13–14pt, Bold, Underlined).
  * Department Shaded Bar: `{{DEPARTMENT}}` enclosed in a shaded `#D9D9D9` single-border cell.
* **Evaluation Block (Right-aligned):**
  * `Total Marks: XX` (Underlined)
  * `Marks Obtained: ______` (Underlined)

### Pattern B: Full-Width Title Block with Instructor Slots
* **Course Title:** Centered, 22–26pt Bold Times New Roman.
* **Assignment Label:** Centered, 16–18pt Bold Underlined (e.g., `Assignment # 01`).
* **Due Date:** Centered, 11–12pt Bold Underlined.
* **Credentials Slots:**
  * `Submitted To: [Instructor Name]` followed by horizontal rule.
  * `Student Name: {{STUDENT_NAME}}` followed by horizontal rule.
  * `Reg Number: {{STUDENT_ID}}` followed by horizontal rule.

### Pattern C: Minimalist Header (IEEE / Technical Style)
* Compact multi-line header at the top of Page 1 without a full cover page.
* Course Name, Assignment Title, Student Name, Student ID, and Date aligned cleanly in standard black typography.

### Pattern D: Strict Professor Cover Template Preservation
* When the professor provides an assignment brief in Word or PDF format with their own pre-designed title page, **Pattern D is mandatory**.
* Replicate the original Page 1 geometry with 100% fidelity, and cleanly inject `{{STUDENT_NAME}}` and `{{STUDENT_ID}}` into the designated blanks without breaking margins or spilling into Page 2.

## 📂 Subject Directory Structure
Every generated assignment is saved inside its designated subject directory:
`<output_dir>/<Subject_Name>/`

Examples:
* `./output/Digital Image Processing/Assignment_01_Digital_Image_Processing.docx`
* `./output/Business Technology and Ethics/Assignment_01_BTE.docx`
* `./output/Computer Science/Assignment_03_Data_Structures.docx`
* `./output/Applied Physics/Applied_Physics_Assignment_03.docx`
