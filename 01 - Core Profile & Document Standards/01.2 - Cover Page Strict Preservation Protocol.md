# 📄 01.2 - Cover Page Strict Preservation Protocol

> **The Golden Law:** *Never break, refactor, or 'modernize' the professor's cover page. Preserve 100% layout and typographic fidelity.*

When a professor provides an assignment brief (in PDF or DOCX), Page 1 represents their established institutional template. Rebuilding or modifying the layout immediately tips off examiners that an external tool generated the paper.

---

## 🛠️ Step-by-Step Cover Page Preservation Workflow

### Step 1: Asset & Layout Extraction
1. **Extract Official University Logos:**
   Run `pdfimages -png input.pdf logo_out` to extract the exact raster logo embedded in the professor's PDF. Do not download generic low-res logos from Google Images.
2. **Measure Geometry & Margins:**
   Inspect whether Page 1 uses standard margins (0.75 in top/bottom, 0.8 in left/right) or custom margins.
3. **Inspect Outer Frame Borders:**
   Check if the assignment has an outer boundary box. If present, inject `<w:pgBorders>` XML in the section properties.

### Step 2: Slot Filling Without Layout Rupture
* If the original cover page has:
  ```
  Student Name: ______________________________________________________________________________
  Reg Number:   _______________________________________________________________________________
  ```
* Fill the text directly into the designated slot, preserving the underline rule:
  ```
  Student Name:   [Student Name]
  ______________________________________________________________________________
  Reg Number:      [Registration / Student ID]
  _______________________________________________________________________________
  ```
* Match the exact font size (11–12pt), font family (Times New Roman), weight (Bold), and line spacing of the surrounding template.
* Never push the title page content onto Page 2. Page 1 MUST remain strictly confined to a single page, ending with a clean programmatic `doc.add_page_break()`.

---

## 🏷️ XML Code Snippets for DOCX Title Page Integrity

### 1. Outer Page Border (`<w:pgBorders>`)
```python
sectPr = doc.sections[0]._sectPr
bdr_xml = r'<w:pgBorders %s w:offsetFrom="page"><w:top w:val="single" w:sz="6" w:space="24" w:color="000000"/><w:left w:val="single" w:sz="6" w:space="24" w:color="000000"/><w:bottom w:val="single" w:sz="6" w:space="24" w:color="000000"/><w:right w:val="single" w:sz="6" w:space="24" w:color="000000"/></w:pgBorders>' % nsdecls("w")
sectPr.append(parse_xml(bdr_xml))
```

### 2. Shaded Department Bar (`#D9D9D9`)
```python
tbl_dept = doc.add_table(rows=1, cols=1)
c_dept = tbl_dept.cell(0, 0)
c_dept.width = Inches(6.9)
shd = parse_xml(f'<w:shd {nsdecls("w")} w:fill="D9D9D9"/>')
c_dept._tc.get_or_add_tcPr().append(shd)
```
