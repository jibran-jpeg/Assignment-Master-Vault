# 🗄️ 05.2 - Reference Scripts & Templates Index

This index highlights production-grade script architectures that demonstrate the Anti-AI and formatting standards across different academic domains:

1. **Digital Image Processing (DIP) Architecture:**
   * **Features:** Comprehensive technical reporting, custom 300 DPI matplotlib diagrams, 2D Fourier sampling math, SQNR step-by-step derivations, discrete pixel matrix tables (APA 7th compliant), and Hounsfield scales.
   * **Core Standards:** Defined interior matrix grids (`insideH`, `insideV` in 0.5pt `#B0B0B0`), `#EAEAEA` shaded matrix headers, and standalone centered equation blocks without tables.

2. **Business Technology & Ethics (BTE) Architecture:**
   * **Features:** Deep multi-page case study analysis, stakeholder impact matrices, Kantian categorical imperative, utilitarian calculations, Rawlsian veil of ignorance, and full Ethics Management Programs (EMP).
   * **Core Standards:** Narrative thesis-driven prose, zero robotic bullet repetition, elimination of generic AI tables, and organic synthesis paragraphs.

3. **Computer Science & Software Engineering Architecture:**
   * **Features:** Multi-page programming assignments, clean monospace Consolas/Courier code listings, execution output trace panels, and step-by-step memory allocation walkthroughs.
   * **Core Standards:** Title page reproduction with pixel-fidelity, `#000000` text color enforcement, and explicit dry-run trace matrices.

4. **Applied Physics & Mathematics Architecture:**
   * **Features:** Formal problem-solution structures, step-by-step symbolic and numerical derivations, dimensional unit calculations, and vector diagram plotting.
   * **Core Standards:** Word native superscripts/subscripts, standard mathematical Unicode symbols, and zero callout boxes.
