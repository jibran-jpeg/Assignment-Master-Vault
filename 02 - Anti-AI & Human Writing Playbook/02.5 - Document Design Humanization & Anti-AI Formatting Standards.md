# 🎨 02.5 - Document Design Humanization & Anti-AI Formatting Standards

> **The Golden Law:** *"AI detection does not happen only through text; human evaluators detect AI within 3 seconds of looking at the visual layout of a Word document. A document that looks like a web blog or a Notion export in MS Word is immediately flagged as AI-generated."*

---

## 🔬 The Anatomy of Visual AI "Slop" in MS Word

When an evaluator, professor, or reviewer opens an assignment in Microsoft Word, several unconscious visual cues immediately signal AI generation:

| Artificial AI Visual Cue | Why It Fails | Human Academic Standard |
| :--- | :--- | :--- |
| **The CSS/Notion Callout Card** | Single-cell boxes with thick left accent borders (`border-left: 3px solid black`) and grey fill. Real students NEVER make web callouts in Word! | **Indented text blocks** or **APA 7th Edition tables** with zero vertical borders. |
| **Formulaic Key-Value Repeats** | Repetitive symmetrical schemas across every section (e.g., `Moral Breach: ... Direct Victims: ... Legal Exposure: ...` repeated verbatim 3 times). | **Natural analytical prose** with organic heading titles and varied sentence structures. |
| **The 4x4 Grid Matrix Table** | Full-grid tables with borders on all four sides, identical cell word counts, and robotic bullet points trapped in boxes. | **APA 7th Publication Format**: 3 horizontal lines only, no vertical borders, formal Table N caption. |
| **Corporate Accent Headers** | Blue (`#0056B3`), cyan, or purple section headings generated by default LLM styles. | **100% Solid Academic Black (`#000000`)** across all text, headers, and rules. |
| **Awkward Table Row Splits** | Table cells breaking in half across page boundaries due to missing Word XML properties. | Strict `<w:cantSplit/>` on every row and `<w:tblHeader/>` on header rows. |
| **Flat Cadence & Monotony** | Every paragraph is precisely 4 sentences long and 80 words, with identical rhythmic pacing. | **High Burstiness**: Short 8-word punchy conclusions alternating with complex 35-word multi-clause analyses. |

## 🏛️ The 5 Pillars of Human Document Craftsmanship

### Pillar 1: Authentic Academic Typography & Hierarchy
Human university students use native Microsoft Word styles, not web UI elements:
* **Font Family:** `Times New Roman` (Standard for Humanities, Law, Ethics, Academic Papers) or `Calibri` (for modern technical/engineering reports).
* **Document Title:** 15.5pt – 16.0pt, Bold, Centered, `#000000`.
* **Heading 1:** 13.0pt – 13.5pt, Bold, `#000000`, 16pt space before, 6pt space after, `keep_with_next = True`.
* **Heading 2:** 11.5pt – 12.0pt, Bold, `#000000`, 10pt space before, 4pt space after, `keep_with_next = True`.
* **Body Paragraphs:** 11.0pt Regular, `#000000`, 1.15 line spacing, 0pt space before, 6pt space after, Justified alignment.
* **List Bullets:** Standard Word bullet (`style="List Bullet"`), 1.15 line spacing, 4pt space after, bold title prefix.

---

### Pillar 2: Professional Academic & Technical Table Standards (Crisp Grid Borders)
Tables must be purposeful, structured, and visually anchored:
1. **The Floating Table Trap Banned:** Never leave technical numbers, calculation steps, or 2D image matrices floating in empty white space with only 3 horizontal lines and zero vertical or interior lines. It looks detached, unfinished, and gives an artificial AI-generated vibe.
2. **Defined Grid Borders for Engineering & Numerical Tables:**
   * Top and bottom borders: solid `#333333` (0.75pt–1.0pt / `sz="8"`).
   * Left and right outer borders: solid `#B0B0B0` (0.5pt / `sz="4"`).
   * Interior horizontal rules (`w:insideH`): subtle single line (`#B0B0B0` / `sz="4"`).
   * Interior vertical rules (`w:insideV`): subtle single line (`#B0B0B0` / `sz="4"`).
3. **Shaded Header Row:** The column header row MUST have subtle neutral shading (`#EAEAEA` or `#E0E0E0`) with bold text and a solid `#333333` rule beneath.
4. **2D Matrix Array Presentation:** For 2D raster matrices (e.g. 7×7 image arrays), shade column headers (`#EAEAEA`), row headers (`#F0F0F0`), and the junction cell (`#D9D9D9`) with compact padding to represent an authentic pixel array.
5. **Alternating Row Shading (Zebra Striping):** For multi-row calculation tables (10+ rows), use subtle alternating row shading (`#FFFFFF` and `#F8F9FA`) to maximize scanning comfort.
6. **Formal Academic Caption (Above the Table):**
   * **Table 1** (in 10pt Bold on line 1)
   * *Descriptive Title in Italics* (in 10pt Italic on line 2)
7. **Row Integrity:**
   * `<w:cantSplit/>` attached to every `<w:trPr>` so rows never split across page margins.
   * `<w:tblHeader/>` attached to the header row so headers repeat on multi-page tables.

---

### Pillar 3: Absolute Universal Ban on Web Callout Containers & Shaded Boxes
* **NEVER** insert single-cell tables with thick left borders (`w:left w:sz="16"` or `w:sz="24"`) and shaded backgrounds (`#FBFBFB`, `#F9F9F9`, or `#F5F5F5`) for ANY purpose in Microsoft Word.
* In Word, that visual pattern is the **#1 visual dead-giveaway of an automated AI generator**. It immediately looks like a web CSS markdown blockquote or Notion export.
* **Universal Scope (Including Math & Formulas):** Real students NEVER put equations inside bordered grey boxes or monospace Consolas blocks. Mathematical formulas must be clean, borderless centered paragraphs formatted in Times New Roman with italicized variables and native sub/superscripts.
* **The Human Replacement:** For conceptual analysis, use standard narrative paragraphs with natural bold lead-ins or APA 7th tables. For math, use borderless centered paragraphs.

---

### Pillar 4: Structural Heterogeneity & Natural Cadence
A real student does not write every question with the exact same template:
* In **Dilemma 1**, focus on the legal violation and constitutional privacy rights.
* In **Dilemma 2**, provide a detailed narrative breakdown of enterprise contractual fraud and engineering ethics.
* In **Dilemma 3**, use crisp bullet points to highlight copyright statutes and advertising regulations.
* Avoid rigid metadata labeling like *"Summary Assessment A"*, *"Summary Assessment B"*. Real students write natural descriptive subheadings like *"Synthesis of Systemic Harms Across Stakeholder Tiers"*.

---

### Pillar 5: Preserving Official Institutional Cover Standards
When completing university assignments:
* Always preserve the exact official cover page layout provided by the instructor:
  * Official university logo and department banner.
  * Border frame (`<w:pgBorders>` XML).
  * Exact submission credentials (`Submitted To:`, `Student Name:`, `Reg Number:`).
* Never alter the cover structure or replace it with a generic template.

### 1. APA 7th Edition Table Styler
```python
def set_apa_table_borders(table, border_color="222222", border_sz="8"):
    tblPr = table._tbl.tblPr
    borders = parse_xml(
        f"<w:tblBorders {nsdecls("w")}>\n"
        f"  <w:top w:val="single" w:sz="{border_sz}" w:space="0" w:color="{border_color}"/>\n"
        f"  <w:bottom w:val="single" w:sz="{border_sz}" w:space="0" w:color="{border_color}"/>\n"
        f"  <w:left w:val="none"/>\n"
        f"  <w:right w:val="none"/>\n"
        f"  <w:insideH w:val="none"/>\n"
        f"  <w:insideV w:val="none"/>\n"
        f"</w:tblBorders>"
    )
    tblPr.append(borders)

    for row in table.rows:
        trPr = row._tr.get_or_add_trPr()
        trPr.append(parse_xml(f"<w:cantSplit {nsdecls("w")}/>"))

    header_trPr = table.rows[0]._tr.get_or_add_trPr()
    header_trPr.append(parse_xml(f"<w:tblHeader {nsdecls("w")}/>"))

    for cell in table.rows[0].cells:
        tcPr = cell._tc.get_or_add_tcPr()
        h_border = parse_xml(
            f"<w:tcBorders {nsdecls("w")}>\n"
            f"  <w:bottom w:val="single" w:sz="6" w:space="0" w:color="{border_color}"/>\n"
            f"</w:tcBorders>"
        )
        tcPr.append(h_border)
```

### 2. APA Table Caption Builder
```python
def add_apa_table_caption(doc, table_num, title_text):
    p = doc.add_paragraph()
    p.paragraph_format.space_before = Pt(8)
    p.paragraph_format.space_after = Pt(2)
    p.paragraph_format.keep_with_next = True
    
    r_num = p.add_run(f"Table {table_num}\n")
    r_num.font.name = "Times New Roman"
    r_num.font.size = Pt(10)
    r_num.font.bold = True
    r_num.font.color.rgb = RGBColor(0, 0, 0)
    
    r_title = p.add_run(title_text)
    r_title.font.name = "Times New Roman"
    r_title.font.size = Pt(10)
    r_title.font.italic = True
    r_title.font.color.rgb = RGBColor(0, 0, 0)
    return p
```

### 3. Native Bold Run-in List Bullet Builder
```python
def add_bullet_item(doc, bold_title, body_text):
    p = doc.add_paragraph(style="List Bullet")
    p.paragraph_format.space_before = Pt(0)
    p.paragraph_format.space_after = Pt(4)
    p.paragraph_format.line_spacing = 1.15
    p.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY

    r_bold = p.add_run(bold_title + ": ")
    r_bold.font.name = "Times New Roman"
    r_bold.font.size = Pt(11)
    r_bold.font.bold = True
    r_bold.font.color.rgb = RGBColor(0, 0, 0)

    r_body = p.add_run(body_text)
    r_body.font.name = "Times New Roman"
    r_body.font.size = Pt(11)
    r_body.font.color.rgb = RGBColor(0, 0, 0)
    return p
```
