# ✅ 06.2 - Quality Assurance Pre-Flight Checklist

Before marking any assignment as complete, run through this rigorous 12-point checklist:

- [ ] **1. Student Identity:** Are Student Name and Registration / Student ID accurately embedded on Page 1 without disrupting title alignment?
- [ ] **2. Cover Page Integrity:** Is Page 1 completely preserved without spilling onto Page 2? Are logos, department boxes, and underlines aligned?
- [ ] **3. Outer Frame Border:** Does the document feature the required `<w:pgBorders>` XML frame if present in the institutional template?
- [ ] **4. Text Color Check:** Is all body text, heading text, and label text strictly standard black (`#000000`)? Are all AI blue/teal colors banned?
- [ ] **5. No Em-Dashes:** Are all section titles free of `—` and `–`? (Use hyphens `-` or colons `:` instead).
- [ ] **6. Banned Phrase Audit:** Has the document been searched for blacklisted words (*"in conclusion"*, *"delving into"*, *"crucial to note"*, *"tapestry"*, *"beacon"*)?
- [ ] **7. Universal Ban on Web/Notion Callout Boxes & Math Shading:** Are there zero single-cell tables with thick left borders (`border-left`) and grey background shading? Are all mathematical equations formatted as clean, borderless centered paragraphs in Times New Roman without boxes or background fill?
- [ ] **8. Professional Table Quality & Crisp Borders:** Are numerical calculation tables and 2D matrix arrays formatted with clean grid borders (`#B0B0B0`, 0.5pt) and shaded header rows (`#EAEAEA`)? Are floating, borderless empty tables avoided? Does every table have a formal `Table N` bold caption and `<w:cantSplit/>`?
- [ ] **9. Organic Structural Heterogeneity:** Does the document avoid repetitive, cookie-cutter key-value schemas repeated across sub-sections? Are presentation structures varied naturally?
- [ ] **10. Mathematical & Code Rigor:** Are all equations properly derived with intermediate steps? Are code snippets formatted in monospace Consolas?
- [ ] **11. High-Res Visuals:** Are all embedded figures rendered at 300 DPI with formal figure captions?
- [ ] **12. Dual Output Verification:** Has the file been saved as clean `.docx` and successfully compiled into `.pdf` via LibreOffice without errors or orphaned lines?
