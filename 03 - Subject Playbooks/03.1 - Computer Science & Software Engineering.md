---

## 🛠️ Code Formatting Rules
* **Monospace Font:** Always format code in `Consolas` or `Courier New` 9.5pt.
* **Line Spacing:** 1.0 single spacing, 0pt space before, 1pt space after.
* **Cell Container:** Light grey background (`#F8F9FA`), left blue/charcoal border (`#0056B3` or `#333333`), hairline borders around.
* **Proper Indentation:** Strict 4-space indentation.
* **Execution Output Block:** Always follow code with a dedicated program output block showing actual terminal outputs.

## 🧠 Memory & Execution Trace Tables
Human students always include variable state traces when solving algorithmic or pointer problems:

```markdown
Iteration | Pointer *ptr | Variable x | Stack State       | Output Produced
-------------------------------------------------------------------------
1         | 0x7ffd10     | 10         | [main: x=10]      | Initialized
2         | 0x7ffd14     | 25         | [func: a=25, x=10]| Memory updated
```
